Virtual visit of the Koeberle high school library
==================================================

This is a 360-degree virtual tour generated with the Marzipano Tool. The
panorama tiles and supporting files are included in this repository.

Local preview
-------------

Open `index.html` through a local web server. Browsers may block some resources
when the page is opened directly as a `file://` URL.

GitHub Pages
------------

The workflow in `.github/workflows/pages.yml` publishes the tour whenever
changes are pushed to `main`. In the repository's Settings > Pages, select
`GitHub Actions` as the build and deployment source. After the first successful
workflow run, the site will be available at:

https://yoanwoan.github.io/visite-virtuelle6DU6KOEB/
